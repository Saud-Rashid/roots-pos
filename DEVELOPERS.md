# 🍹 ROOTS POS System

A modern, fast, and responsive Point of Sale (POS) system designed for **ROOTS**. Built using HTML, CSS, JavaScript, and integrated tools to provide a seamless sales management and billing experience.

---

## ✨ Features

- 🛒 **User POS Interface:** Easy-to-use checkout screen for fast order placement.
- 👨‍🍳 **Admin Panel & Dashboard:** Manage sales, view reports, and track operations.
- 📊 **Excel Exporting:** Powered by SheetJS (`xlsx.full.min.js`) for exporting data directly to Excel sheets.
- 🎨 **Modern UI/UX:** Clean, modern design with custom fonts and FontAwesome icons.
- 📱 **Responsive Design:** Optimized across various device screens.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Icons & Styling:** FontAwesome 6.4.0, Google Fonts (Plus Jakarta Sans)
- **Data Exporting:** SheetJS Library
- **Deployment:** Vercel
