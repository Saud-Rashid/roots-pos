# 🍹 ROOTS POS System

A modern, high-performance Point of Sale (POS) system custom-built for **ROOTS**. Designed for seamless daily sales transactions, administrative overview, and inventory export capabilities.

---

## 🚀 Live Demo & Documentation

- **Live Preview:** [ROOTS POS System](https://roots-pos-xi.vercel.app)
- **Setup Guide:** Refer to `SETUP_GUIDE.md`
- **Developer Details:** Refer to `DEVELOPERS.md`

---

## ✨ Key Features

- 🛒 **User POS Interface:** Fast and intuitive interface for placing quick orders.
- 👨‍🍳 **Admin Panel:** Complete overview of sales, orders, and system settings.
- 📊 **Excel Sync & Export:** SheetJS-powered automated export features.
- 🔒 **Security Layer:** Built-in JS security validations (`security.js`).
- ⚡ **Lightweight & Fast:** Pure HTML, CSS, and JS — zero unnecessary dependencies.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Libraries:** SheetJS (Excel Export), FontAwesome 6.4.0
- **Deployment:** Vercel
